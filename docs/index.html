hekouwang-writer-skill 是一个中文写作质量控制 Agent Skill：写文档、修文章、做体检，保护出处、数字、模态和原意。

适合内容创作者、研究人员、产品/运营，以及需要交付正式中文文档的人。

WHAT IT DOES

你给它一个具体任务，
它交付一份可核对的结果。

DOCUMENT MODE · DEFAULT

“把这份材料整理成办事指南。”

适合方案、报告、说明、邮件、汇报、家庭文档。先判断读者和目的，再用 WRITE 五步装进结构。

交付：成稿 + 进度卡 + 必要的检查结果
ARTICLE MODE

“先诊断，再把这篇文章写得像人。”

适合公众号、头条和长文章母版。保留事实、原意和信息密度，不编第一人称，不承诺绕过检测。

交付：诊断清单 + 改写文本 + 事实保留说明

THREE GUARANTEES

三个不会被顺手抹掉的东西。

01

出处

政策、数字、专有名词查不到出处，就标注“暂无出处”，不编造。

02

模态

“约、可能、待核实”是事实的一部分，不会被润色成确定语气。

03

修订

改动逐条列出，复杂修订可用脚本对账；脚本只报告，不自动覆盖原文。

QUALITY TOOLING

规则不是口号，
有脚本可以检查。

六个 Python 标准库工具，按任务复杂度触发。advisory 只提醒，hard 才阻断。

  • sawdust_scan.py锯末词密度 · advisory
  • sentence_load.py句长与分句堆叠 · advisory
  • rhythm_scan.py文章节奏 · advisory
  • doc_lint.py表格与标题层级 · hard
  • check_fidelity.py算术关系 · hard
  • change_list.py改前/改后对账 · strict

三步开始使用

仓库本身就是产品。按你的 Agent 宿主放入 Skill 目录，再给它一个具体任务。

01 · 下载

克隆 writer-skill 仓库。

git clone https://github.com/huiyonghkw/hekouwang-writer-skill.git
02 · 安装

复制到宿主识别的 Skill 目录。

CodeBuddyClaude CodeCursorCodex

各宿主目录与发现规则不同，请按宿主配置；不要把 CodeBuddy 路径照搬到其他工具。

03 · 开始任务

给它材料和目标，说明事实边界。可以直接复制下面这段指令。

FIRST TASK · COPY PROMPT

请把这份会议材料整理成一页汇报。先确认读者和目的，不要补写材料中没有的事实；数字、日期和“可能/待确认”等表述都要保留。最后列出你做了哪些改动，以及哪些信息还需要我确认。
