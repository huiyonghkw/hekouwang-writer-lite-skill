用户要求

只检查错漏、歧义和数字关系

用户明确说“先告诉我问题，不要直接改文件”。因此检查器只报告，不覆盖原文。

报告格式
位置问题建议
第 2 节“下月”缺少明确日期保留为待确认，询问是否有已批准日期
表 1合计与分项不一致复核来源，不能擅自挑一个数字替换
advisory

提醒，但不阻断

sawdust_scan.py、sentence_load.py、rhythm_scan.py 命中告警时进程仍返回 0。

hard

确定性错误可阻断

doc_lint.py 的结构错误和 check_fidelity.py 的算术不一致可返回 1。

本文没有真实方案文件，也未运行检查器。真实任务要对用户提供的原文件运行，并如实报告实际输出。
