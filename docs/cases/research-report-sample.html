01 / 场景何时用

先把证据级别说在前面。

本例的问题是：三款写作检查工具里，哪一款在中文长文样本上的误报最低？样本为 12 篇虚构占位稿，每工具各 4 篇；其中 8 篇按 A 级（读过全文并复跑）、3 篇按 B 级（只读摘要）、1 篇按 C 级（仅见目录）处理。结论按证据级别打折，只做相对排序，不做绝对排名。

适用

立项调研、工具选型、竞品分析

不适用

学术论文、咨询深度报告

边界

占位数据，不可当真实调研引用

本页全部工具名用示例代号 A / B / C，样本数、误报数与出处均为占位；出处路径只是示意，不是可打开的链接。
02 / 骨架七节

正文按七节走，每节只回答自己的问题。

  1. 摘要结论、现在做什么、最大风险
  2. 方法与样本选样、证据分级、不覆盖什么
  3. 发现逐条结论带证据级别
  4. 对照同口径表格，合计能对账
  5. 结论可执行建议，不越过证据
  6. 局限样本、未读全文、没查到的项
  7. 依据材料、示意地址、用于哪一节

七节骨架只给结构，不替用户生成正文；没查到就写「这次没查到」，不补写。

判定口径写死，不让两张表各说各话。

06 / 高危四条

四种写法最容易让结论撑不住。

跨源合并数字

不同口径的百分比直接相加，合计行看着整齐但对不上出处。

摘要结论撑不住

只读过摘要的样本按全文结论写，证据级别被悄悄抬高。

局限性空写

只写「样本有限」，不写哪几篇没读全文、哪个平台没测。

假靶心对比

「不是 A 而是 B」里的 A 没有来源，属于无源的稻草人。

07 / 交稿本页状态

示意页：脚本未执行。

真实任务要对用户提供的原文件运行检查器，并如实报告实际输出；证据对账表按脚本结果填写，不预先替用户判定。若随后授权修订，才进入修订模式并列出改动清单。
