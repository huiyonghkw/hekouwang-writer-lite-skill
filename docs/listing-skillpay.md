# SkillPay 商品文案（仓库副本）

本文件是支付宝 SkillPay 平台商品页文案在仓库里的副本，**不随安装包分发**（`docs/` 已被 `.clawhubignore` 排除）。

平台的商品描述是手写字段，仓库之外没有第二个来源。改版本前先比对这里，否则新版本加了能力而描述没跟，重审会以「商品描述与上传文件能力说明不一致」驳回。

当前上架包：付费版 1.7.0（公开版 1.6.4 + `paid/` 增量），由 `paid/build_package.py` 生成。

## 商品名称

会勇禾口王 · 写作技能

## 商品描述

平台限制 500 字。当前 375 字（平台计数 369，换行不计）。

```text
对得上账的中文写作质控，两种模式。
文档模式：方案、报告、说明、办事指南、家庭文档、邮件、汇报的结构化写作与修订；文档体检查长句、锯末词、数字对账、待核实项；修订逐条列改动、可回退。
文章模式：依据素材或研究包写公众号、头条正文；去 AI 味先诊断再分档改写，保留事实、原意和信息密度。
三条铁律：出处（查不到标“暂无出处”，不编造）、模态（约/可能/待核实原样保留）、修订（不悄悄改用户的事实）。
9 个纯 Python 标准库脚本：6 个检查器（锯末词、句长负荷、文章节奏、文档格式、数字对账、改前改后差异对账）+ 3 个订阅版工具（数字台账、目录批量体检可出 HTML 报告、术语表草稿生成）；全部只报告不改写。
三套场景包：政务办事指南、项目汇报、公众号长文，各含材料清单、口径陷阱与验收问题。
不适用：无素材的营销文案、诗歌小说、英文写作。
```

## 商品页链接

购买链接在仓库里只存两份副本：`docs/index.html` 安装区第 1 步的按钮、`README.md` 顶部的链接行。产品页其余位置与 6 个案例页页脚一律指页内锚点 `#buy`，不要再复制长链。

商品编号与审核状态仍以创作者后台为准，不写进仓库。

## 发版核对清单

1. 包内能力有变化 → 先改本文件，再改平台。顺序反了就是拿旧描述送审。
2. 描述里每条都要在包内找得到落点：模式、铁律对应 `SKILL.md`，脚本对应 `scripts/`。
3. 名称、价格、试用次数没变就不要动；买断/订阅不可更改；更新商品信息不会重置用户剩余试用次数。
4. 描述或文件任一改动都要重新提审，审核通常 1–3 分钟。
5. 商品编号、审核状态属于平台侧信息，以创作者后台为准；购买链接只存上面说的两处，商品重建时才需要改。
