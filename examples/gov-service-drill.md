# 练习卷：办事指南里的三种假账（故意写错）

> **这是练习卷，不是真案例，也不是真政策。**  
> 下面「错稿」里埋了三个常见坑。按步骤跑脚本，对得上期望结果，才算会用本 Skill 查办事稿。

## 你要练什么

| 坑 | 人眼容易怎样 | 靠什么抓住 |
|---|---|---|
| 合计算错 | 表看着整齐 | `check_fidelity.py` |
| 两个接口的限制写成一条 | 数字没错，范围错了 | `scope_lint.py` |
| 关键数字没有出处卡 | 改完对不上材料 | `provenance_card.py` |

## 错稿（请整段另存为临时文件再查）

把下面保存成例如 `/tmp/gov-drill-bad.md`：

```markdown
# 某地居民养老提档示意（练习稿 · 事实虚构）

## 摘要

她要补差。合计自筹 **50,000 元**。月养老金大概 661。

## 钱怎么算

| 项 | 金额 |
|---|---|
| 12 年补差 | 46,400 元 |
| 2025 补缴 | 4,000 元 |
| 2026 缴 | 4,000 元 |
| 合计自筹 | 50,000 元 |

对账：46,400 + 4,000 + 4,000 = 50,000 元。

## 接口限流（整理自两份接口说明书）

| 能力 | 限制 |
|---|---|
| 外呼与 webCall | 200 次/分钟 |

说明：两份说明书里其实只有 webCall 写了 200 次/分钟；外呼那份没写频次。本表故意写错。
```

## 怎么跑

在 skill 目录下（把路径换成你的安装位置）：

```bash
BAD=/tmp/gov-drill-bad.md   # 先把上面错稿存成这个文件

python3 scripts/check_fidelity.py "$BAD"; echo exit:$?
python3 scripts/scope_lint.py "$BAD"; echo exit:$?
python3 scripts/provenance_card.py "$BAD"
```

## 期望结果（对上才算过关）

### 1. `check_fidelity.py` → 退出码 1

应打出类似：

- 「合计自筹」金额列：三项之和 = **54400**，表中为 50000  
- 加法链：46400 + 4000 + 4000 = **54400**，文中写 50000

核心是：**拦住算错**。

### 2. `scope_lint.py` → 退出码 1

至少命中一类：

- 限制表缺少「接口／小节／来源」列；或  
- 正文／表里把「外呼」与「webCall」绑在同一条 200 次/分钟上

### 3. `provenance_card.py` → 退出码 0，并给出草稿表

表里应出现带单位的数，例如 `46,400` 元、`4,000` 元、`200` 次 等；  
「来源小节」一列应是 **【待填】**。  
练习动作：把 `200 次` 那一行的来源改成「仅 webCall 文档 · 请求频次」，状态改「已核实」；外呼一行标「待核实／文档未写」。

### 4. 人眼必抓（脚本不管）

摘要里「月养老金大概 661」丢了单位和「约」——改稿时应写成 **661 元（约）**，并注明未计入项。这道题用来练模态铁律，不要求脚本报警。

## 改对之后长什么样（要点，不是完整公文）

1. 合计与等式改为 **54,400 元**（或按你的正确分项重算后两边一致）。  
2. 限流表拆成两行，并有来源列：

| 接口 | 限制 | 来源小节 |
|---|---|---|
| webCall | 200 次/分钟 | webCall 文档「请求频次」 |
| 外呼 | 未标注 | 外呼文档未写频次 |

3. 回复里附补全后的数字出处卡；进度卡写明跑过哪些脚本、退出码。
